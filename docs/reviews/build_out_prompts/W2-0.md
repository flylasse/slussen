Rules for this phase:
- AGENTS.md §2 in full: plain English; defined terms in Title Case; entity and attribute names in code notation; every number that the Operator experiences is an Operator Setting with its default, or a fixed number with its source; the entity model's closed vocabulary for data types and validation rules; use case steps at business level.

- A use case stays `**Status:** Approved`; the changes are proposed and the operator approves them at the end of the run.
