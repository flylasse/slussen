## To fix in this phase, with the orchestrator's decisions

1. **CONFIRMED. A waiting import, or an open choice of the Bank Account, is visible and can be left only at the control that started it, and disables every other import control without a word** (`TransactionFileImportViewModel.kt:56, 77`). Cases: the choice among two Bank Accounts is open on one Budget tab, the Operator goes elsewhere, and every import control is disabled with no reason until he goes back and cancels; an import waits behind a long Fetch, the Operator leaves, and it starts unseen whenever the lane is free. **Decision:** every import control says what runs or waits and for which Bank Account, and offers Withdraw while it waits; an open choice of the Bank Account ends when its screen is left.
2. **CONFIRMED. An answer and its lines stay at their place for the life of the process**, with the Transaction Statuses as they were at the import (`:211-215`). Case: the answer shows "Needs Review" under the Source; the Operator decides; every later reload still shows "Needs Review" there. **Decision:** the answer with its lines is shown until the Operator leaves that screen or another operation ends; after that the stored Source Health says what was imported.
3. **PLAUSIBLE. A7 can lose its choice of file without a word** (`SlussenActivity.kt:385-390`): the request to go on with the import is consumed before the import is started, and the start can be refused because another import runs; and when the Operator leaves before Add completes, the dialog opens at his next visit. **Decision:** the import is started first; a refusal is answered at the form (the Bank Account is added, and the file is imported from its Source afterwards); the dialog opens only while the page that asked is still shown.
4. **PLAUSIBLE. Memory.** A file read whole and converted: an out-of-memory error in the conversion ends the app (only the read turns it into a failure), and after a failed read for lack of memory the answer says to choose the file again, which fails the same way. **Decision:** both are answered at the control as a file too large for this device, nothing stored, the lane released.
5. **PLAUSIBLE, minor. "Could not be read" can be said when the Budget App was read** (`FileImportTexts.kt:145` decides from the statuses being absent, not from the outcome's own word that the Comparison failed).
6. **PLAUSIBLE, minor. The File Format page's message can be lost in a race** between the reload after an operation ends and the form's own (`FileFormatViewModel.kt:84-95`): the message is kept whatever the order.
